# assets — 여기에 사진·포스터를 넣어요

| 파일 이름 | 쓰이는 곳 | 권장 크기 |
|---|---|---|
| `hero.jpg` | 첫 화면 배경 또는 대표 사진 | 가로 1600px 안, 1MB 안 |
| `poster.jpg` | 포스터 섹션 | 세로 포스터 그대로, 1MB 안 |
| `item-1.jpg` `item-2.jpg` `item-3.jpg` | 메뉴·상품 카드 | 정방형 800px |
| `logo.svg` 또는 `logo.png` | 상단 로고 | 세로 48px 기준 |

같은 이름으로 넣으면 `index.html`을 고치지 않아도 바로 보여요. 파일이 없으면 자리표시 블록이 대신 보여요.
